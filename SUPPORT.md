# Support

## How to file issues and get help

This repository uses GitHub Issues to track bugs and feature requests. Please search the [existing issues](https://github.com/EndstoneMC/scripting-nodejs-release/issues) before filing a new one to avoid duplicates, and read [TROUBLESHOOTING](TROUBLESHOOTING.md) for what a report needs. For a new issue, file your bug or feature request [here](https://github.com/EndstoneMC/scripting-nodejs-release/issues/new/choose).

For questions about using the plugin, please use the [Discussions page](https://github.com/EndstoneMC/scripting-nodejs-release/discussions) or the [Endstone Discord](https://discord.gg/xxgPuc2XN9).

For questions about the server software itself rather than the scripting runtime, see the [Endstone repository](https://github.com/EndstoneMC/endstone) and the [Endstone documentation](https://endstone.dev/).

## Support policy

Support for this project is limited to the resources listed above.
